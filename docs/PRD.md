# 「画个啥」产品与设计 PRD

> 版本：v1.0 · 2026-10 · 产品：DoodleGuess（画个啥）
> 一句话：抽一张词卡，把它画出来，让 AI 在 100 个词里猜。

---

## 1. 背景与目标

「你画我猜」的乐趣在于“画得不像也能被猜中”的惊喜。市面上多数版本需要真人房主或后端识别服务；本项目希望做成一个**打开就能玩、识别完全在本地完成**的小网页：不登录、不上传、不依赖任何 AI API。

- 数据来源：Google [QuickDraw Dataset](https://github.com/googlecreativelab/quickdraw-dataset)（CC BY 4.0）。
- 识别方式：用 QuickDraw 的 28×28 位图训练一个轻量分类器，随前端打包，在浏览器内推理。
- 产品目标：3 秒内理解玩法，60 秒内完成一次“画 → 猜 → 中”的完整循环。
- 非目标：多人联机、账号体系、云端同步、复杂绘画工具。

## 2. 用户与场景

| 用户 | 场景 | 需求 |
|---|---|---|
| 随手玩一下的访客 | 课间 / 摸鱼 / 和朋友分享屏幕 | 不用注册，点开就能画 |
| 喜欢涂鸦的人 | 想看看 AI 能把自己的“灵魂画作”猜成什么 | 好玩的反馈、可保存作品 |
| 家长 / 老师 | 陪孩子玩画词游戏 | 中文词卡、无外链、无广告 |

## 3. 核心玩法

### 3.1 词卡挑战（主模式）
1. 系统从 100 个词中抽一张词卡（emoji + 中文 + 英文），最近 30 张不会重复；只有全部词都进过最近列表时才会重新出现。
2. 用户在白纸上作画，限时 90 秒。
3. 点击「让 AI 猜猜」，AI 给出 Top-3 猜测与把握度。
4. Top-1 命中 → 猜中；目标在 Top-3 → 差一点；否则 → 没猜中。
5. 猜中自动收进画廊；失败也可以手动保存。自由画在未猜测时也能直接保存。

### 3.2 自由画
不计时、不设目标词。用户想画什么画什么，AI 从 100 类里给 Top-3。适合展示和测试模型；也可以不猜，直接保存这幅自由画。

### 3.3 状态机
```
首页 ──开始画画──▶ 画板(挑战) ──猜中──▶ 结果印章 ──▶ 再来一张 / 回首页
  │                   │  └──未中──▶ 继续画 / 保存
  └──自由画──────────▶ 画板(自由)
  └──我的画廊────────▶ 画廊 ──▶ 作品详情
```

## 4. 视觉设计

### 4.1 关键词
**水彩纸、蜡笔、手账、贴纸、印章、绘本**。界面像一张被反复使用的画纸：有纸纹、有胶带、有没对齐的边，但信息层级必须清楚。

- 不要：玻璃拟态、霓虹渐变、标准 Material 卡片、过度圆角。
- 要：米白纸底、可见的墨线、轻微旋转、色块边缘的“水痕”。

### 4.2 色板

| Token | 色值 | 用途 |
|---|---|---|
| `--paper` | `#FBF6EA` | 页面纸底 |
| `--paper-deep` | `#F3E9D2` | 卡片/画纸阴影 |
| `--ink` | `#2E2A26` | 主文字、手绘线 |
| `--ink-soft` | `#6B6258` | 次级文字 |
| `--coral` | `#F28C6B` | 主按钮、水彩块 |
| `--tomato` | `#E4572E` | 强调、错误、印章 |
| `--mustard` | `#F2B134` | 高亮、Top-1 条形 |
| `--sage` | `#8FBF9F` | 成功、辅助水彩 |
| `--sky` | `#7FB3D5` | 辅助水彩、链接 |
| `--plum` | `#B58DB6` | 辅助水彩 |
| `--white` | `#FFFDF8` | 画纸本体 |

水彩块统一 `mix-blend-mode: multiply`、透明度 0.35–0.6，边缘用 SVG 湍流位移做出不规则水痕。

### 4.3 字体
- 标题 / 按钮：`ZCOOL KuaiLe`（站酷快乐体，OFL）。自托管 `src/assets/fonts/zcool-kuaile.woff2`，来源 `@fontsource/zcool-kuaile`，已按界面用字子集化。
- 正文 / 数据：`"PingFang SC", "Microsoft YaHei", "Noto Sans SC", sans-serif`。
- 英文词：同正文，字距 0.02em，字号为中文的 0.72 倍。
- 标题字号：桌面 clamp(56px, 8vw, 104px)；移动端 44–56px。
- 数字（计时、百分比）：`font-variant-numeric: tabular-nums`。

### 4.4 图形语言
- 所有装饰线：2–3px、圆头、路径带 1–2px 的手抖；避免完美圆和直线。
- 卡片边框：2px 墨线 + 不规则 `border-radius`（如 `255px 18px 225px 18px / 18px 225px 18px 255px`）。
- 阴影：`4px 5px 0 rgba(46,42,38,.12)`，模拟纸片叠放，不用模糊大阴影。
- 胶带：半透明姜黄/鼠尾草色矩形，两端锯齿，旋转 ±4°。
- 印章：砖红双线圆角矩形，文字「猜中啦」，倾斜 -8°，带轻微油墨缺口。
- 图标：统一自绘 SVG，24×24 viewBox，`stroke-linecap: round`，视觉重量一致。

### 4.5 布局
- 最大内容宽 1200px，页面左右留白 24–48px。
- 首页：左文右画（≥960px），移动端上下堆叠。
- 画板：画纸 + 右侧 AI 面板（360px）；<900px 时 AI 面板落到画纸下方。
- 画廊：`auto-fill minmax(220px, 1fr)` 网格，卡片随机旋转 -1.5°~1.5°。

## 5. 动效设计

| 元素 | 触发 | 时长 / 缓动 | 说明 |
|---|---|---|---|
| 页面切换 | 进入页面 | 260ms `cubic-bezier(.22,1,.36,1)` | 8px 上移 + 淡入 |
| 首页涂鸦漂浮 | 常驻 | 7–12s `ease-in-out` 循环 | 位移 6–10px + 旋转 2° |
| 水彩色块 | 常驻 | 14–22s 循环 | 缓慢缩放/位移，透明度呼吸 |
| 主按钮 hover | 指针进入 | 160ms | 上移 2px、阴影变长、轻微 -1° 旋转 |
| 画纸入场 | 进入画板 | 320ms | 从 0.97 缩放、-1° 回正 |
| 笔尖落纸 | pointerdown | 80ms | 光标圆圈收缩 |
| AI 思考 | 点击猜测 | 700–900ms | 三点跳动 → 画纸扫描线 → 翻牌 |
| 猜测翻牌 | 结果返回 | 320ms，逐条 +80ms | Y 轴 90° → 0°，轻微回弹 |
| 猜中印章 | 命中 | 420ms `cubic-bezier(.2,1.6,.4,1)` | 1.6 → 1 缩放，-8° 旋转，墨点扩散 |
| 纸屑 | 命中 | 900–1400ms | 24 片，随机颜色/角度/漂移 |
| Toast | 保存/错误 | 220ms 进入，2.4s 后退出 | 底部上浮 |
| 倒计时告急 | ≤15s | 1s 循环 | 数字变砖红 + 轻微脉冲 |

所有动效在 `prefers-reduced-motion: reduce` 下改为无位移/无循环，仅保留透明度变化。

## 6. 交互设计

### 6.1 首页
- 主按钮「开始画画」→ 随机词卡 + 挑战模式。
- 次按钮「自由画」→ 自由模式。
- 右上「我的画廊」显示作品数角标。
- 底部统计：总计（挑战模式里小猜被考的次数，自由画不计）、猜中次数、当前连中、命中率（猜中 / 总计，无数据时显示引导文案）。
- 声音开关：默认关闭；开启后才有按钮、落笔、撤销、猜中 / 没猜中音效。音效使用 CC0 录音（OpenGameArt / Freesound），裁剪为 0.1–1.5s 的短样本，由 Web Audio 解码后叠加播放，来源见 `docs/CREDITS.md`。**当前版本音效暂时关闭**：素材与实现保留在 `src/assets/sounds/` 和 `src/lib/sound.ts`，恢复步骤写在该文件顶部。

### 6.2 画板
- 工具栏：8 色、3 档笔刷、橡皮、撤销、重做、清空。
- 笔刷：细线 6 / 马克笔 16 / 水彩刷 30（1024 逻辑坐标），见 `drawing.ts` 的 `BRUSHES`；渲染层用二次贝塞尔平滑，分类器仍使用原始点。
- 压感：`pointer.pressure` 映射到 0.65–1.35 倍线宽；鼠标固定 1 倍。
- 撤销/重做按笔迹重放，不设固定步数上限；清空需二次确认。
- 快捷键：`Ctrl/⌘+Z` 撤销，`Shift+Ctrl/⌘+Z` 重做，`E` 橡皮，`B` 画笔，`Enter` 猜测。
- 墨迹过少（覆盖率 < 1.5%）时猜测按钮禁用，按 Enter 兜底提示 Toast「墨迹太少，小猜看不清」。
- 倒计时结束自动触发一次猜测；之后不再重复计时。
- 换一题：重置画布与计时，不改变本轮统计。

### 6.3 AI 面板
- 空闲：「小猜」头像 + 「画好了就叫我」。
- 思考：扫描线在画纸上来回，文案轮换（「让我眯眼看…」「这个轮廓有点意思…」）。
- 结果：Top-3，含排名、emoji、中文、英文、把握度条。
- 命中：金色高亮 + 印章覆盖层。
- 未中：显示「目标词在 Top-3 吗」的提示；可「继续画」或「保存这幅」。
- 目标词在 Top-3 但非 Top-1：文案「差一点！它排第 N」。
- 置信度显示：<5% 标注「瞎猜的」；其余显示整数百分比。

### 6.4 画廊
- 卡片显示画作、目标词、日期、AI Top-1；猜中的卡片盖小印章。
- 点击打开详情：大图、Top-3、目标词、用时、「保存为图片」、删除。「保存为图片」与「分享」导出的都是同一张横版卡片：左侧画作，右侧「画廊藏品」标题、目标词、日期 / 用时 / 作品类型，以及 Top-3 猜测与置信度（第 1 名带皇冠标记）。
- 清空画廊二次确认。
- 空状态：手绘空画框 + 「第一幅画，从一只猫开始？」+ 去画画按钮。
- 存储上限 100 幅，超出时自动清理最旧作品，并在保存 Toast 中提示清理数量。

### 6.5 错误与边界
- 模型加载失败：AI 面板显示「识别模型没加载出来」+ 重试按钮；绘画与保存仍可用。
- IndexedDB 不可用：降级到 localStorage（仅保留最近 10 幅）。
- 画布尺寸变化：按逻辑坐标重绘，不丢笔迹。
- 离开画板且未保存：二次确认「画还没收进画廊，确定离开？」。
- 浏览器禁用手势/触控滚动：画布上 `touch-action: none`。

## 7. 识别系统

### 7.1 类别
100 个可画性强的 QuickDraw 类别，中文名与 emoji 见 `src/data/categories.json`：
动物 28、自然 14、食物 16、物品 26、交通/场景 16。

### 7.2 模型
- 输入：28×28 灰度，0–255。
- 结构：784 → 512 ReLU → 256 ReLU → 100，Dropout 0.1。
- 训练：QuickDraw `numpy_bitmap`，每类约 1200 张（过滤低墨量后 108,000 张）；随机旋转 ±12°、缩放 0.88–1.12、平移 ±2px；Adam，label smoothing 0.05。
- 体积：int8 量化权重，约 550KB，随 `public/model/` 打包。
- 指标：留出集 Top-1 **59.4%**、Top-5 **83.9%**（`training/metrics.json`）；验收线为 Top-1 ≥ 55%、Top-5 ≥ 80%。`pnpm verify:model` 会在训练未使用的新样本上复核导出模型。
- 推理：浏览器内矩阵乘 + softmax，单次 < 20ms；不上传任何图像。

### 7.3 预处理
1. 按笔迹顺序重放（橡皮擦用 `destination-out`）。
2. 计算墨迹包围盒，等比缩放并居中到 28×28（留 2px 边距）。
3. 归一化线宽约 2px 后做 4× 超采样，再降采样到 28×28。
4. alpha 通道转灰度，得到分类器输入。

### 7.4 结果判定
- 目标词 = Top-1 → 猜中。
- 目标词 ∈ Top-3 → 差一点。
- 其余 → 未猜中。
- 「把握度」直接展示 softmax 概率，不做虚假放大。

## 8. 数据设计

### 8.1 IndexedDB
数据库 `doodle-guess`，对象仓库 `artworks`，keyPath `id`。

```ts
interface Artwork {
  id: string;              // crypto.randomUUID()
  createdAt: number;
  image: string;           // WebP dataURL, 720×720
  targetId: string | null; // 自由画为 null
  targetZh: string;
  targetEmoji: string;
  mode: 'challenge' | 'free';
  guesses: { id: string; zh: string; emoji: string; confidence: number }[];
  success: boolean;
  durationMs: number;
}
```

### 8.2 localStorage
- `doodle-guess-stats-v1`: `{ guesses, wins, streak, bestStreak }`
- `doodle-guess-sound-v1`: `'on' | 'off'`

### 8.3 图片规格
- 画廊图：720×720 WebP，质量 0.85，白纸底，单张目标 < 80KB。
- 下载图：按作品实际尺寸转 PNG（默认 720×720，不做放大）。

## 9. 响应式与无障碍

- 断点：900px（画板双栏 → 单栏）、640px（首页字号/按钮）。
- 画布保持 1:1；工具栏在窄屏横向滚动，不换行挤压。
- 所有图标按钮有 `aria-label`；模态框 `role="dialog"` + `aria-modal`，Esc 关闭。
- 焦点环：2px 砖红虚线，offset 3px。
- 正文对比度 ≥ 4.5:1；按钮文字 ≥ 16px。
- 画布提供 `aria-label="画板，用鼠标或手指作画"` 与文字说明。
- 颜色不是唯一信息：Top-1 同时用皇冠图标和加粗标注。

### 6.6 PWA / 离线

- 构建产物注册 Service Worker，预缓存 HTML、JS、CSS、字体、模型和 PWA 图标（约 1MB）。
- 首次加载完成后可断网刷新，模型推理与画廊（IndexedDB）继续可用；可从浏览器安装为独立应用。
- 开发模式不启用 Service Worker，避免影响热更新。

### 6.7 备份与恢复

- 画廊提供「导出备份」：把当前作品（含 WebP 图、目标词、Top-3、时间与来源）写成 JSON 文件；不包含模型。
- 「导入备份」校验 app 标识、版本、图片 data URL 与字段结构，跳过无效记录，单次最多导入 200 幅；导入后刷新画廊。
- 备份是用户主动操作，不自动上传任何数据。

### 6.8 安全头 / CSP

- 生产构建注入 CSP meta：`default-src 'self'`、`script-src 'self'`、`style-src 'self' 'unsafe-inline'`、`img-src 'self' data: blob:`、`font-src 'self'`、`connect-src 'self'`、`worker-src 'self'`、`manifest-src 'self'`。
- 主题初始化脚本外置为 `theme-init.js`，避免为 CSP 放开 `script-src 'unsafe-inline'`。
- `public/_headers` 提供 Netlify 风格的安全响应头（含 `frame-ancestors 'none'`、`X-Frame-Options`、`Referrer-Policy`、`Permissions-Policy`）。
